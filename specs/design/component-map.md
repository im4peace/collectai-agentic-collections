# CollectAI Component Map

Maps every story (54 story files, E1-S1 to E11-S6) to the files it creates and modifies, plus the API endpoints and tables it touches. Layout is defined in `folder-structure.md`; endpoints in `api-contracts.md`; tables in `data-models.md`.

Path prefixes: `be/` = `backend/src/collectai/`, `bt/` = `backend/tests/`, `ev/` = `backend/collectai_eval/`, `fe/` = `frontend/src/`, `e2e/` = `frontend/e2e/`. A path ending in `/` denotes a directory whose files are created by that story. "Modifies" lists files created by an earlier story (never a later-slice story) that this story extends. Tests live next to the story in the named `bt/` or `fe/` or `e2e/` directory and are named `test_<story>_*.py` (backend) or `*.test.tsx` / `*.spec.ts` (frontend).
