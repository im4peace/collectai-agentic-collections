# E11-S5: Automated accessibility verification suite

- **ID:** E11-S5
- **Epic:** E11 - End-to-End Journey Verification
- **Layer:** UI
- **Slice:** 1
- **Group:** I
- **depends_on:** E3-S3, E6-S5, E7-S6

## Description

Automated axe checks, keyboard-navigation and focus-management tests for the primary screens and journeys, run in CI. WCAG 2.1 AA remains a target, not a certification claim.

## Acceptance Criteria

1. An axe scan runs in Playwright on every primary screen delivered so far (persona switcher, Portfolio, Customer 360, Chat, escalation list) and fails on any serious or critical violation
2. Keyboard-navigation tests reach and operate every interactive control on the primary journeys without a mouse and show a visible focus indicator
3. Focus-management tests confirm focus moves into dialogs and confirmations on open, is trapped while open, returns to the trigger on close, and new chat messages are announced through a live region
4. A test asserts that AI, rules-engine, risk, priority and simulated states each carry a text or icon label and never rely on color alone
5. The suite runs in CI and its reporting states that the product targets WCAG 2.1 AA and makes no conformance claim
