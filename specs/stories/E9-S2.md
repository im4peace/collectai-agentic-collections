# E9-S2: Audit Trail Viewer screen

- **ID:** E9-S2
- **Epic:** E9 - Audit, Governance and Demo Controls
- **Layer:** UI
- **Slice:** 1
- **Group:** G
- **depends_on:** E9-S1, E3-S4

## Description

Build the audit viewer presenting the decision chain in language a PM or compliance stakeholder can follow, with versions of model, prompt and rule set visible.

## Acceptance Criteria

1. Searching by account id or correlation id shows the decision chain as an ordered, labelled timeline of the six stages
2. Each AI step displays model id, prompt version and PolicyRuleSet version
3. The viewer has no edit or delete controls and passes axe with zero serious or critical violations
4. The timeline is keyboard navigable, each stage is identified by a text label, and the viewer is reachable only by COMPLIANCE_RISK
