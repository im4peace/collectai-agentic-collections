# E10-S4: Collections and AI Performance Dashboard

- **ID:** E10-S4
- **Epic:** E10 - Evaluation, Analytics and Portfolio Deliverables
- **Layer:** UI
- **Slice:** 4
- **Group:** K
- **depends_on:** E10-S3, E3-S4

## Description

Build the manager dashboard with separate Business, Operational and AI quality sections, clearly labelling MOCK, LIVE and ILLUSTRATIVE data. It is built last, after the journey slices.

## Acceptance Criteria

1. The dashboard has three headed sections Business, Operational and AI quality and governance each listing its KPIs from the API
2. Every KPI tile shows a text badge ILLUSTRATIVE, MOCK or LIVE and MOCK and LIVE AI values are in separate tiles
3. A LIVE recall tile for a category with fewer than 30 cases shows 'observation only' and no percent-pass indicator
4. The dashboard is read-only (no mutation controls) and passes axe with zero serious or critical violations
5. Only COLLECTIONS_MANAGER can open the dashboard route and every other persona sees the forbidden page with no KPI data rendered, and the dashboard is keyboard operable
