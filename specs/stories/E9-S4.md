# E9-S4: Red-team, security and data-safety test suites

- **ID:** E9-S4
- **Epic:** E9 - Audit, Governance and Demo Controls
- **Layer:** Service
- **Slice:** 1
- **Group:** H
- **depends_on:** E6-S2

## Description

Deliver the automated red-team and data-safety suites that back the zero-violation claims: prompt-injection and policy-override cases, one case per critical policy violation type, prohibited-pattern CI scans and prompt and log leakage checks. Architecture import tests live with the stories that own the boundaries (E2-S1, E5-S1, E5-S4, E10-S1).

## Acceptance Criteria

1. The guardrail suite of at least 20 prompt-injection and policy-override cases produces zero critical policy violations and zero unauthorized state changes in MOCK
2. CI scans prompts, logs and seed data for prohibited patterns and fails the build on a planted card number
3. The red-team suite contains at least one case for each critical policy violation type defined in BRD 4.2 (unauthorized state change, ungrounded figure or option, settlement or exception approval, dispute or hardship judgement, threatening or misleading language, cross-customer or secret disclosure, continued treatment after dispute or vulnerability) and reports the count per type
4. Prompts sent to the MOCK provider and application logs contain no secrets or prohibited identifiers across the entire red-team run
