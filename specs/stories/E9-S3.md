# E9-S3: Dev and demo controls

- **ID:** E9-S3
- **Epic:** E9 - Audit, Governance and Demo Controls
- **Layer:** UI
- **Slice:** 1
- **Group:** I
- **depends_on:** E6-S4, E3-S4

## Description

Provide flag-gated demo controls to show the LIVE or MOCK mode, advance the Clock, reseed data and trigger a simulated payment. Disabled by default and never available to other personas' production paths.

## Acceptance Criteria

1. With the flag off, the control routes return 404 and the panel is not rendered; with the flag on the panel shows mode as text 'MOCK' or 'LIVE'
2. Advance-clock control moves the simulated Clock by the chosen days and a subsequent breakage run marks due PTPs BROKEN
3. The simulated-payment trigger creates a PaymentEvent with source demo control and simulated=true
4. Reseed restores the seeded dataset and every control action writes an audit event
