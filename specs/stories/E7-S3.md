# E7-S3: Escalation and Review Queue screen

- **ID:** E7-S3
- **Epic:** E7 - Escalation and Human Review
- **Layer:** UI
- **Slice:** 2
- **Group:** J
- **depends_on:** E7-S5, E7-S6

## Description

Build the full review queue list and case detail with conversation, AI recommendation and deterministic rule results shown separately, queue filters, the reviewer action controls with mandatory reason fields, and the compliance decision view for COMPLIANCE_RISK. It extends the minimal Slice 1 escalation list.

## Acceptance Criteria

1. The list shows reason, priority, aging and source for each case and sorts by priority then age
2. Case detail shows the conversation, the AI recommendation and the deterministic rule results in three separately labelled sections
3. Action buttons for REJECT, MODIFY and ESCALATE stay disabled until a reason is entered, and APPROVE is hidden when the API reports it is not permitted
4. A stale-version conflict displays a message that the case changed and reloads the case, and the screen passes axe with zero serious or critical violations
5. The queue can be filtered by COLLECTIONS_REVIEW, COLLECTIONS_EXCEPTION_REVIEW, HARDSHIP_REVIEW, DISPUTE_REVIEW and VULNERABLE_CUSTOMER_REVIEW with text labels for queue, priority and aging
6. COMPLIANCE_RISK sees only the COMPLIANCE_REVIEW queue with the compliance decision controls, and COLLECTIONS_OFFICER does not see those controls
7. Action dialogs move focus into the reason field on open, trap focus while open and return focus to the action button on close, and every action is operable by keyboard
