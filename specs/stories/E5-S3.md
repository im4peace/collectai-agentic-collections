# E5-S3: Grounding check, prompt allow-list and redaction

- **ID:** E5-S3
- **Epic:** E5 - AI Orchestration Foundation
- **Layer:** Service
- **Slice:** 1
- **Group:** C
- **depends_on:** E5-S1

## Description

Enforce that customer-facing AI text only contains currency figures, dates and options returned by deterministic services, replacing violations with templated text. Restrict prompt inputs to an allow-list and redact sensitive data in logs (BRD 13.1 rows 3 and 16).

## Acceptance Criteria

1. A post-generation check extracts currency figures, dates and option identifiers from AI text and blocks the message if any is absent from the service results in context
2. A blocked message is replaced by templated text built from the service output and a grounding-violation event is counted for the hallucination metric
3. A message whose figures all match service results passes unchanged
4. Prompt construction includes only allow-listed fields and a test that adds a forbidden field (for example national_id) to the context proves it is excluded from the prompt
