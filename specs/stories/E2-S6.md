# E2-S6: Escalation routing service

- **ID:** E2-S6
- **Epic:** E2 - Deterministic Rules Engine
- **Layer:** Service
- **Slice:** 1
- **Group:** B
- **depends_on:** E1-S1, E1-S2

## Description

Implement the deterministic routing service that maps an escalation reason from the approved enum to a review queue, reviewer role and priority using the active versioned PolicyRuleSet. The LLM proposes only a reason and never selects a destination. Unknown reasons fail closed to COLLECTIONS_REVIEW.

## Acceptance Criteria

1. For each of the 11 EscalationReason values the routing service returns the contract queue and reviewer role: REQUEST_HUMAN, UNRESOLVED_UNKNOWN, AI_FAILURE_FALLBACK, SETTLEMENT_REQUEST and AMBIGUOUS_VALIDATION to COLLECTIONS_REVIEW and COLLECTIONS_OFFICER; EXCEPTIONAL_ARRANGEMENT to COLLECTIONS_EXCEPTION_REVIEW and COLLECTIONS_OFFICER; FINANCIAL_HARDSHIP to HARDSHIP_REVIEW and COLLECTIONS_OFFICER; DISPUTE to DISPUTE_REVIEW and COLLECTIONS_OFFICER; VULNERABLE_CUSTOMER to VULNERABLE_CUSTOMER_REVIEW and COLLECTIONS_OFFICER; POLICY_EXCEPTION and HIGH_RISK_COMPLIANCE to COMPLIANCE_REVIEW and COMPLIANCE_RISK
2. An unrecognized or missing reason fails closed to COLLECTIONS_REVIEW and COLLECTIONS_OFFICER and the result is flagged reason_unrecognized
3. The routing function accepts only the reason and case context and never a queue or reviewer role argument, and its result contains reason, queue, reviewer role, priority and the PolicyRuleSet version used
4. VULNERABLE_CUSTOMER and FINANCIAL_HARDSHIP cases receive at least the ELEVATED priority defined by the routing priority parameters, and identical inputs always return the identical priority
5. If the active rule set is unavailable the routing service returns the COLLECTIONS_REVIEW fallback with POLICY_UNAVAILABLE recorded and never an empty routing
