# E1-S5: Reproducible local development and CI

- **ID:** E1-S5
- **Epic:** E1 - Foundation, Policy and Persistence
- **Layer:** Config
- **Slice:** 1
- **Group:** C
- **depends_on:** E1-S3

## Description

Provide documented local startup, database setup, migrations, synthetic seeding, MOCK-only test execution and a basic CI workflow so the portfolio project is reproducible. No production deployment scope.

## Acceptance Criteria

1. A README documents local startup and one documented command starts PostgreSQL, the API and the web app with Docker Compose from a clean checkout
2. A documented command applies migrations and loads the synthetic seed data, and the API reports ready afterwards
3. MOCK mode is the default and the full backend and frontend test suites run locally with no ANTHROPIC_API_KEY set and no network calls to the provider
4. A basic CI workflow runs backend, frontend and MOCK evaluation tests on every push, fails on any test failure, and excludes LIVE evaluation
5. No production deployment configuration is included: only local Compose files and the CI workflow exist
