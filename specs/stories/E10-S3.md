# E10-S3: KPI aggregation API

- **ID:** E10-S3
- **Epic:** E10 - Evaluation, Analytics and Portfolio Deliverables
- **Layer:** API
- **Slice:** 4
- **Group:** J
- **depends_on:** E6-S4, E10-S2, E8-S1, E8-S2, E8-S3

## Description

Expose read-only KPI endpoints implementing the complete BRD 4.5 KPI tree derivable from MVP data: business, operational and AI quality metrics, each with definition, formula, data label (ILLUSTRATIVE, MOCK or LIVE) and owner persona. Access is COLLECTIONS_MANAGER only. Deferred KPIs stay absent.

## Acceptance Criteria

1. GET /api/kpis returns total delinquent accounts, total overdue amount, recovered amount, recovery rate, PTP rate and promise-kept rate computed with Decimal from seeded data and simulated PaymentEvents
2. Each KPI includes definition, formula, data label and owner persona and business KPIs carry label ILLUSTRATIVE
3. Escalation rate, queue size and aging, time-to-review and human override rate are computed from EscalationCase and decision data
4. AI KPIs are returned separately for MOCK and LIVE and the deferred KPIs (right-party contact, handling time, cost per collected account) are absent
5. Only COLLECTIONS_MANAGER can read the KPI endpoints and CUSTOMER, COLLECTIONS_OFFICER and COMPLIANCE_RISK receive 403
6. The customer-resolution and completeness KPIs PTP breakage rate, self-service resolution rate, arrangement take-up rate, hardship case count and dispute case count are returned with definition, formula and data label
