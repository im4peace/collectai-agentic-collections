# E8-S4: Dispute review and resolution

- **ID:** E8-S4
- **Epic:** E8 - Arrangements, Hardship and Disputes
- **Layer:** Service
- **Slice:** 3
- **Group:** I
- **depends_on:** E8-S3, E7-S2

## Description

Enable a human reviewer to record a dispute outcome and reason, update dispute status through audited transitions and release or maintain suppression accordingly.

## Acceptance Criteria

1. Resolving a dispute requires an outcome (for example UPHELD, REJECTED, WITHDRAWN) and a non-empty reason, otherwise 422
2. Dispute status moves only OPEN to UNDER_REVIEW to RESOLVED and each transition writes an audit event with the reviewer persona
3. After resolution the item suppression is lifted only when the outcome is recorded and remains for the item while the status is not RESOLVED
4. Only COLLECTIONS_OFFICER can resolve a dispute and CUSTOMER, COLLECTIONS_MANAGER and COMPLIANCE_RISK receive 403 on the resolve operation
5. Submitting the same dispute resolution with the same idempotency key returns the original result and does not repeat the transition or its audit event
