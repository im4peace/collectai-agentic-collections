# E3-S1: Persona RBAC enforced server-side

- **ID:** E3-S1
- **Epic:** E3 - Access Control and Delinquent Portfolio
- **Layer:** API
- **Slice:** 1
- **Group:** D
- **depends_on:** E1-S4

## Description

Implement demo persona resolution and a role by endpoint authorization layer. Personas are switchable without real authentication but every endpoint enforces permissions for the active persona and audits denials (D-019). COMPLIANCE_RISK is read-only apart from the single narrow record_compliance_review_decision capability. Screen access follows the BRD: Audit Trail for COMPLIANCE_RISK, Dashboard for COLLECTIONS_MANAGER.

## Acceptance Criteria

1. A request without a persona header returns 401 and a request from a role not allowed on an endpoint returns 403 with body code FORBIDDEN
2. Every 403 produces an audit event containing persona, endpoint and correlation id
3. A generated role x endpoint matrix test covers every registered route for all four personas and asserts the documented allow or deny outcome
4. COLLECTIONS_MANAGER receives 403 on every mutating endpoint (POST, PUT, PATCH, DELETE), and COMPLIANCE_RISK receives 403 on every mutating endpoint except the record_compliance_review_decision endpoint
5. The record_compliance_review_decision capability is allowed only for COMPLIANCE_RISK and returns 403 for CUSTOMER, COLLECTIONS_OFFICER and COLLECTIONS_MANAGER, and COMPLIANCE_RISK holds no other mutating capability
