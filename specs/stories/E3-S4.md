# E3-S4: Persona switcher and role-based navigation

- **ID:** E3-S4
- **Epic:** E3 - Access Control and Delinquent Portfolio
- **Layer:** UI
- **Slice:** 1
- **Group:** F
- **depends_on:** E3-S5

## Description

Build the persona switcher and navigation shell so each persona sees only the routes it may use, with customer and internal layouts logically separate. The switcher is demo-only, labelled as such, and binds the CUSTOMER persona to one seeded customer.

## Acceptance Criteria

1. The switcher lists exactly CUSTOMER, COLLECTIONS_OFFICER, COLLECTIONS_MANAGER and COMPLIANCE_RISK, selecting one sends that persona on subsequent API calls, and selecting CUSTOMER requires choosing one seeded demo customer whose id is bound server-side
2. Navigation shows only permitted links per persona: CUSTOMER sees Chat only, COLLECTIONS_OFFICER sees Portfolio, Customer 360 and the escalation queues, COLLECTIONS_MANAGER sees the Dashboard only, and COMPLIANCE_RISK sees the Audit Trail and the compliance review queue
3. Navigating directly to a route the persona cannot access shows a forbidden page and does not render restricted data
4. The shell shows a visible 'Demo persona - not real authentication' label and the current persona name as text
5. The persona switcher and navigation are operable by keyboard alone with a visible focus indicator, and the current persona is announced to assistive technology
