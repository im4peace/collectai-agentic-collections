# E7-S6: Minimal escalation list screen (Slice 1)

- **ID:** E7-S6
- **Epic:** E7 - Escalation and Human Review
- **Layer:** UI
- **Slice:** 1
- **Group:** H
- **depends_on:** E7-S1, E4-S2

## Description

Provide the minimal Slice 1 escalation list so escalated cases are visible to officers immediately, without depending on the complete review-queue experience delivered in later slices.

## Acceptance Criteria

1. The minimal escalation list screen shows reason, priority, age, status and a customer and account reference for each case, sorted by priority then age, with text labels as well as color
2. Selecting a case opens the related Customer 360 with the escalation context visible
3. Only COLLECTIONS_OFFICER can open the list and other personas see the forbidden page without any escalation data rendered
4. The list is keyboard operable, passes axe with zero serious or critical violations, and does not depend on the full review queue implementation
