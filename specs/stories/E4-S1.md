# E4-S1: Customer 360 API

- **ID:** E4-S1
- **Epic:** E4 - Customer 360 and Next-Best-Action
- **Layer:** API
- **Slice:** 1
- **Group:** E
- **depends_on:** E3-S1, E2-S1, E2-S4, E2-S5

## Description

Expose a consolidated Customer 360 read model: profile, account, balances, DPD, bucket, priority band and factors, interactions, PTP history, hardship indicators, disputes, escalation status and the current recommendation. AI-generated and deterministic data are separately labelled in the payload.

## Acceptance Criteria

1. GET /api/customers/{accountId}/360 returns profile, account, outstanding balance, overdue amount, DPD, bucket, interactions, PTP history, hardship indicators, disputes and escalation status
2. The payload places priority band and contributing factors under a source='deterministic' block and any recommendation under source='ai' with model id and prompt version
3. An unknown account id returns 404 and CUSTOMER persona receives 403
4. Customer 360 is allowed only for COLLECTIONS_OFFICER and returns 403 for COLLECTIONS_MANAGER and COMPLIANCE_RISK
5. The payload includes the snapshot as_of timestamp, record version and a freshness state of FRESH, STALE or UNKNOWN from the freshness service
