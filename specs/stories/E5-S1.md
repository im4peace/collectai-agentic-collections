# E5-S1: LLM provider abstraction with MOCK and LIVE modes

- **ID:** E5-S1
- **Epic:** E5 - AI Orchestration Foundation
- **Layer:** Service
- **Slice:** 1
- **Group:** B
- **depends_on:** E1-S1, E1-S2

## Description

Create the LLM provider interface with an Anthropic implementation (LIVE) and a scriptable MOCK implementation, selected by configuration. Domain and rules code never import the Anthropic SDK (D-015).

## Acceptance Criteria

1. Mode is chosen by configuration and MOCK makes zero network calls (verified by a test that blocks sockets)
2. The MOCK provider can be scripted to return valid, malformed, adversarial and timeout responses per test case
3. Provider results include model id, latency in ms and token usage where available, and timeouts raise ProviderTimeout after the configured limit
4. Only the ai_orchestration package may import the provider and no other package imports the anthropic SDK (architecture test)
