# E10-S5: Portfolio deliverables P1 to P4

- **ID:** E10-S5
- **Epic:** E10 - Evaluation, Analytics and Portfolio Deliverables
- **Layer:** Config
- **Slice:** 4
- **Group:** K
- **depends_on:** E10-S3

## Description

Generate and maintain the four portfolio documents from project data: KPI tree, AI evaluation report, AI governance risk register and product decision log. This story finalizes them for Slice 4.

## Acceptance Criteria

1. docs/portfolio/kpi-tree.md contains every KPI in the BRD 4.5 tree with definition, formula, data source, owner persona and label, and lists the three deferred KPIs
2. docs/portfolio/ai-evaluation-report.md shows per category dataset provenance, case count, true positives, false negatives, recall, model, prompt version and date, with MOCK and LIVE separate
3. docs/portfolio/ai-risk-register.md has one entry for each of the 27 failure scenarios and the 9 top risks, each with likelihood, impact, control, owner and linked test
4. docs/portfolio/decision-log.md contains every decision in the BRD decision log at generation time, each with status, alternatives and rationale, and a test fails if any decision ID present in the BRD decision log is missing from the file, so new decisions never require editing this criterion
