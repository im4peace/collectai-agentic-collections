# E9-S1: Audit trail API

- **ID:** E9-S1
- **Epic:** E9 - Audit, Governance and Demo Controls
- **Layer:** API
- **Slice:** 1
- **Group:** E
- **depends_on:** E3-S1

## Description

Expose read-only audit trail queries by account, correlation id and time range, returning the decision chain in order: input, AI interpretation, tool or proposal, rule validation, human decision, final state. Access is restricted to COMPLIANCE_RISK.

## Acceptance Criteria

1. GET /api/audit?correlation_id={id} returns events ordered by timestamp with stages INPUT, AI_INTERPRETATION, PROPOSAL, RULE_VALIDATION, HUMAN_DECISION (where applicable) and FINAL_STATE
2. Filtering by account id and date range returns only matching events
3. The audit endpoint is allowed only for COMPLIANCE_RISK, returns 403 for CUSTOMER, COLLECTIONS_OFFICER and COLLECTIONS_MANAGER, and exposes no write route
4. Returned events contain no secrets or prohibited identifiers (scan over responses for 100 events)
