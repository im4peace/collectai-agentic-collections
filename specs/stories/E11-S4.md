# E11-S4: Journey C end-to-end: dispute

- **ID:** E11-S4
- **Epic:** E11 - End-to-End Journey Verification
- **Layer:** Service
- **Slice:** 3
- **Group:** K
- **depends_on:** E8-S4, E7-S3, E9-S2

## Description

Automated end-to-end verification of Journey C: dispute detection, structured capture, treatment pause, escalation, human resolution and audit.

## Acceptance Criteria

1. A Playwright test as the bound CUSTOMER raises a dispute and the system stores a structured category and reason, pauses the disputed item and creates an escalation in DISPUTE_REVIEW
2. An attempt to create a PTP on the disputed item through chat is refused with DISPUTED_ITEM until a human action
3. As COLLECTIONS_OFFICER the case is reviewed and resolved with an outcome and a reason, the dispute becomes RESOLVED, and the UI requires both before submission
4. The audit viewer shows every dispute status transition and the reviewer decision for the journey
