# E6-S5: AI Collections Chat screen

- **ID:** E6-S5
- **Epic:** E6 - Customer Conversation, Promise-to-Pay and Simulated Payment
- **Layer:** UI
- **Slice:** 1
- **Group:** G
- **depends_on:** E6-S1, E3-S4

## Description

Build the customer chat screen with AI disclosure, respectful copy, an always-visible 'Talk to a human' control, explicit confirmation controls and simulated-payment labelling. Responsive for mobile and desktop.

## Acceptance Criteria

1. The chat opens with an AI disclosure message and a 'Talk to a human' button that stays visible throughout scrolling
2. Clicking 'Talk to a human' creates an escalation via the API and shows the message that a human colleague will follow up
3. PTP, payment and arrangement details are shown with Confirm and Cancel buttons, nothing is submitted until Confirm is clicked, and Confirm submits the confirmation API action referencing the displayed proposal id
4. Simulated payment confirmations display a visible 'Simulated payment' label in text
5. The chat is usable at 375 px width with no horizontal scroll, passes axe with zero serious or critical violations and supports keyboard-only sending
6. When the AI provider is unavailable the chat shows a safe message with the 'Talk to a human' option still available, and when handoff creation fails it shows that the handoff could not be completed with a safe next step; no AI reply is fabricated in either state
7. Focus moves into confirmation dialogs on open, is trapped while open and returns to the trigger on close, and new assistant messages are announced through a live region
