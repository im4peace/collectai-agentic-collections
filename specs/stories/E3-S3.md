# E3-S3: Delinquent Portfolio screen

- **ID:** E3-S3
- **Epic:** E3 - Access Control and Delinquent Portfolio
- **Layer:** UI
- **Slice:** 1
- **Group:** F
- **depends_on:** E3-S2

## Description

Build the Portfolio screen for officers showing the account table with filters, sorting and priority band badges, opening Customer 360 on selection. Follows the neutral banking design direction and accessibility rules.

## Acceptance Criteria

1. The table renders columns customer, product type, balance, overdue, DPD, bucket, status and priority band, and the band shows a text label as well as color
2. Selecting DPD, priority band and status filters updates the rows shown and the URL query, and clearing filters restores the full list
3. Clicking the overdue and DPD column headers sorts the table and sets aria-sort accordingly
4. Clicking a row navigates to /customers/{accountId} (Customer 360) and the table passes an axe scan with zero serious or critical violations and is operable by keyboard
5. Portfolio main content is interactive in under 2 s p95 over 30 scripted Playwright loads after one warm-up on the 1,000-account dataset
