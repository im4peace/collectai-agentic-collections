# E3-S2: Delinquent portfolio API with filter and sort

- **ID:** E3-S2
- **Epic:** E3 - Access Control and Delinquent Portfolio
- **Layer:** API
- **Slice:** 1
- **Group:** E
- **depends_on:** E3-S1, E2-S1, E2-S4

## Description

Expose an API listing synthetic delinquent accounts with priority band, filtering by DPD range, priority band and status, and sorting by overdue amount and DPD. Available to the Collections Officer.

## Acceptance Criteria

1. GET /api/portfolio returns items with customer name, account type, outstanding balance, overdue amount, DPD, bucket, collection status and priority band for each account
2. Filtering by dpd_min, dpd_max, priority_band and status returns only matching accounts and combined filters intersect
3. Sorting by overdue amount and DPD ascending and descending returns correctly ordered results using Decimal comparison
4. The portfolio endpoint is allowed only for COLLECTIONS_OFFICER and returns 403 for CUSTOMER, COLLECTIONS_MANAGER and COMPLIANCE_RISK
