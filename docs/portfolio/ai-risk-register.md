# AI governance and risk register (P3)

Portfolio deliverable P3 (BRD 13.5). One entry for each of the 27 failure scenarios in BRD 13.1 and for each of the 9 top expected risks, each with likelihood, impact, control, owner and linked test.

- **Likelihood and impact** are the project author's qualitative assessment on the scale LOW / MEDIUM / HIGH. They are not measurements.
- **Linked tests** are real automated tests, written as `path::test name`. Python entries name the test function; TypeScript and Playwright entries give the test title. Nothing is linked that does not exist.
- **Coverage** is `FULL` when the linked tests exercise the control as described, and `PARTIAL` when part of the control has no test. A `PARTIAL` entry says exactly what is missing in the **Gap** column; gaps are reported, not hidden.
- This is a demonstration project on synthetic data. The controls are simulated policy and demo rules, not regulatory compliance claims (BRD 13.4).

This file is maintained by hand. `backend/tests/portfolio/test_ai_risk_register_doc.py` enforces it: it must contain S1 to S27 and R1 to R9, every entry must fill all fields, and every linked test must exist in the file it names.
